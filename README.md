# U89 Studio OS

نموذج تفاعلي عربي يجمع موقع U89 التسويقي مع نظام إدارة الاستوديو، مع فصل واضح بين ما يراه الزائر وما يراه كل مستخدم بعد تسجيل الدخول.

## ما يعمل في النموذج

- موقع تعريفي وتسويقي خالص يعرض شخصية U89 وخدماته وأعماله، بلا تفاصيل تشغيلية داخلية.
- نموذج بدء مشروع مع حالة نجاح واضحة.
- يطلب نموذج المشروع البريد والجوال وتفضيل التواصل والإشعارات، مع أسئلة تشغيلية قابلة للتعديل من لوحة المالك.
- دخول منفصل للمالك والعميل والمتعاون، ولا يستطيع العميل أو المتعاون تبديل الصلاحية أو فتح لوحة الإدارة.
- لوحة «إدارة الموقع» لتعديل نصوص الصفحة، إظهار الأقسام والخدمات والأعمال، إعداد نموذج الطلب، SEO، بيانات التواصل ووضع الصيانة.
- نشر تغييرات المحتوى داخل النموذج وحفظها في المتصفح حتى بعد إعادة التحميل.
- لوحة يومية تركّز على القرار التالي بدلاً من عرض كل شيء دفعة واحدة.
- إدارة المشاريع ومراحل الطلب والعرض والعقد والتنفيذ والبروفات والتسليم والمتابعة.
- بوابة عميل لمراجعة البروفات واعتمادها أو طلب تعديل.
- بوابة متعاون لعرض المهمة الحالية ورفع التسليم.
- طابور طلبات للعقود التسويقية مع إسناد الطلب إلى عضو الفريق.
- لوحة مالية تجمع مستحقات العملاء ودفعات المتعاونين.
- مركز عروض وعقود ينشئ مسودة قابلة للتحرير، ويفصل قبول العرض عن توقيع العقد وبدء المشروع.
- مركز بريفات يختار قالب الخدمة بعد قبول الطلب، يجمع إجابات العميل، ويقفل عرض السعر حتى اعتماد البريف.
- ثمانية قوالب أولية: قالب متخصص لكل خدمة من الخدمات الست، وقالب حملة، وقالب سريع لمخرج واحد.
- فواتير عميل غير ضريبية ومطالبات تقديم خدمة للمتعاونين بسعر القطعة وعملات متعددة.
- إعدادات مركزية للاسم والحساب البنكي والمواعيد وجولات التعديل وخطط الدفعات والعملات.
- محرر كامل لقوالب البريف يسمح بإضافة الأقسام والأسئلة والاختيارات والملفات والمقاييس وتعديلها أو حذفها.
- مركز «التجربة الكاملة» لمشروع حي واحد من 13 إجراء، مع زر ينقلك إلى الدور والشاشة التي تحتاج القرار التالي.
- حالة مشتركة بين الإدارة والعميل والمتعاون: قبول الطلب، تعبئة البريف، العرض، العقد، الدفعات، رفع البروفة، دورة التعديل، التسليم والتقييم.
- حفظ تقدم المشروع التجريبي في المتصفح، مع زر لإعادة السيناريو من البداية في أي وقت.
- وضع فاتح وداكن وتصميم متجاوب، مع وصول كامل لأقسام الإدارة من قائمة «المزيد» على الجوال.

## تجربة السيناريو الكامل

1. افتح «دخول المنصة» ثم اختر «إدارة الاستوديو».
2. افتح «التجربة الكاملة» من القائمة الجانبية.
3. اضغط «انتقل إلى الإجراء» واتبع القرار الظاهر فقط.
4. استخدم شريط الأدوار العلوي للتبديل بين الإدارة والعميل والمتعاون عند الحاجة.
5. يمكنك طلب تعديل على البروفة، ثم رفع النسخة الثانية من مساحة المتعاون واعتمادها من بوابة العميل.
6. بعد إكمال التجربة استخدم «إعادة السيناريو» للبدء من طلب جديد.

## التشغيل المحلي

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:5173`.

## بناء نسخة الإنتاج

```bash
npm run build
npm run preview
```

ينتج مجلد `dist` الجاهز للنشر.
